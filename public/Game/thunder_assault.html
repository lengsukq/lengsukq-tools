📖 银河战术指挥手册 (GAME MANUAL)
雷霆战机：银河突围 全平台操作指南与作战机制说明
🎮 游戏手柄控制 (GAMEPAD)

完美支持 Xbox / PlayStation DualSense / Switch Pro / PC 蓝牙手柄，即插即用：

  • 左摇杆 / 十字键：360° 模拟飞行移动（带 0.18 死区过滤）
  • A 键 / RT 键：主炮持续开火（与自动开火叠加）
  • B 键 / LT 键：释放【全屏核爆 EX Bomb】
  • X 键 / LB 键：能量满格时激活【狂暴超载 Hyper】
  • Y 键：按住进入低速聚焦微操（显示核心判定点）
  • Start 键：暂停 / 继续战斗；准备 / 升级 / 结算界面可用 A 键确认
  • 震动反馈：擦弹轻震、受击中震、核爆/Boss 重震
⌨️ 键盘与鼠标 (KEYBOARD & MOUSE)
  • W / A / S / D 或 方向键：战机全向飞行
  • 鼠标移动：战机平滑跟随（默认自动开火）
  • 空格 / J / 鼠标左键：持续开火
  • K / E / 鼠标右键：释放全屏核爆（BOMB）
  • Shift：低速聚焦微操（移速 -50%，点亮核心判定点）
  • P / Esc：暂停游戏
📱 触屏移动端 (TOUCH CONTROLS)
  • 单指拖拽：战机跟随手指（智能上方 50px 偏移，手指不挡飞机）
  • 右下角 💣 按钮：释放全屏核爆
  • 右下角 ⚡ 按钮：能量满格时激活狂暴超载
  • 顶部状态栏：可快速切换音效、手册与暂停
✨ 擦弹系统 (Graze System)

战机核心判定点仅中心 6px 半径。敌弹从机身边缘掠过而未命中判定点时，迸发金色电弧火花并计入【擦弹】：快速积累狂暴能量、提升得分倍率（最高 5.0x），连击 2.5 秒不擦弹即衰减。幻影游侠擦弹半径更大（45px）、充能更快，是高分速刷首选。

⚡ 狂暴超载 (Hyper Overload)

黄色能量槽蓄满 100% 后自动激活：瞬间净化全屏敌弹并转化为得分水晶，随后 8 秒超频狂暴——射速 +60%、伤害 +50%、星空进入曲率拉伸特效。建议留到 Boss 弹幕最密阶段开启。

🎯 低速聚焦微操 (Focus Mode)

按住 Shift（手柄按住 Y）进入聚焦：移速降低 50%，机身中央点亮红白核心判定珠宝，幻影游侠弹道聚拢收束，是穿越花瓣弹幕风暴的绝招。

💣 毁灭核爆 (EX Bomb)

开局自带 3 枚核爆：引爆全屏脉冲，歼灭所有敌弹（每发转化为得分）、对全屏敌机造成 400 点真伤。敌机偶有掉落补充，上限 3 枚，Boss 残血斩杀慎用。

🚀 火力压制系
  • 微型巡航飞弹：周期性齐射追踪飞弹，自动索敌轰炸
  • 反应堆超频：主武器射速 +25%/级，狂暴期叠加
  • 聚能暴击矩阵：暴击率 +15%/级，暴击 2.5 倍破片伤害
  • 特斯拉连锁电弧：命中 40% 概率向 180px 内敌机弹射 70% 伤害
🛡️ 生存防御系
  • 战术浮游护卫：每级 +2 架环绕护卫机，自带开火并可撞碎敌弹
  • 偏振护盾重组：护盾上限 +25/级并回满，护盾先承伤
  • 纳米修复集群：装甲持续自愈 2HP/s/级
  • 量子引力吸附：水晶/道具磁吸范围 +90px/级
👾 常规敌舰图鉴
  • 蜂群无人机 (Drone)：直线俯冲 + 单发直射，击杀 120 分，水晶掉率高
  • 拦截者 (Interceptor)：瞄准玩家发射双发扇形弹，击杀 280 分
  • 重型巡洋舰 (Cruiser)：8 向环形弹幕，血厚，击杀 600 分
