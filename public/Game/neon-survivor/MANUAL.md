# 霓虹幸存者：深空裂变 — V3 玩家说明与维护手册

本说明与游戏内「📖 深空战术指挥手册」保持一致。原入口 `/Game/neon_survivor.html` 会跳转至 `/Game/neon-survivor/index.html`，不依赖专用后端。

## 开始与进阶

- 默认开放「标准」难度。标准通关后开放「进阶 I」；继续以当前最高难度通关，依次解锁至「进阶 VI」。
- 在出击前通过开始面板选择难度（鼠标 / 触控点击，手柄十字键左右调整、A 确认）。
- 本次难度在整局内固定；战败或通关后选择「重新部署」可返回开始界面调整。
- 六阶惩罚累计继承；它们**不影响折跃的九段上限**。

| 难度 | 追加挑战 | 普通治疗/磁铁相对掉率 | 全局毁灭相对掉率 |
| --- | --- | ---: | ---: |
| 标准 | 完整四武器、四模组 | 100% | 100% |
| I 敌潮 | 敌人密度提高 | 100% | 80% |
| II 重击 | 敌人伤害 +15% | 95% | 65% |
| III 精英 | 精英出现更频繁 | 90% | 50% |
| IV 匮乏 | 道具减少 | 80% | 35% |
| V 取舍 | 被动模组上限由4槽改为3槽 | 70% | 20% |
| VI 噩梦 | 后期压力提高；Boss 低于60%血量后周期性预警连射 | 60% | 10% |

这些百分比是对**基础掉落概率的乘数**，不是绝对几率。普通怪击杀的标准几率是治疗 1.5%、磁铁 1.1%、全局毁灭 0.9%；进阶 VI 的全局毁灭约为 0.09%。精英怪的治疗道具也按难度下调，Boss 保留经验奖励并分别判定治疗/磁铁。

全局毁灭能够清理普通敌人、对 Boss 造成固定伤害。它击杀的敌人不会继续掉落第二枚全局毁灭，以防无限连锁；经验掉落和击杀记录仍按正常流程结算。

## 折跃与无敌圈

- **等级基础成长**：初始速度240，每升一级速度 +6（等级加成最多120），含推进器在内的总移速上限385；所有武器命中时统一获得每升一级 +3% 的等级伤害（Lv.20约+57%），不依赖升级卡。
- **伤害结算**：等级伤害仅在命中结算阶段计算一次。折跃专精、无尽遗物与破限作为独立来源；「高能粒子折跃刃」满级必定暴击只结算一次暴击倍率，避免后期重复叠加。
- 默认 3 段折跃储能。「折跃储能矩阵」最高 6 级，每级增加 1 段，最终 9 段。能量逐段恢复。
- 使用折跃向移动方向突进；静止时按当前瞄准方向折跃。路径可切割敌人，满级折跃斩仍可附加冻结、火墙和落点爆轰。
- 精准穿越敌人中心可叠加最多 5 层「精准折跃」，每层提升该次精准斩击 8% 伤害；单次折跃最多获得一层。距离上一次精准命中超过 1.2 秒、或折跃未精准命中时连击中断。精准奖励不返还折跃充能，也不增加无敌时间。
- 「时空相位无敌光环」由原来 5 级调整为 6 级，持续时长依次为 **0.15 / 0.20 / 0.25 / 0.30 / 0.35 / 0.40 秒**。它同时具备近身击退、脉冲伤害和顶级结束时八向激光。
- 折跃动作保护与光环保护**重叠计算，不相加**，单次触发的保护最多 0.40 秒。受击后的短暂无敌属于另一项规则。
- 无敌圈破限强化伤害与范围，不再永久堆高保护时长；折跃恢复速度存在下限，九段折跃不能无限循环防护。

## 传说被动：星穹火控矩阵

- 旧「弹幕倍增核心」升级为「星穹火控矩阵」，保留内部标识 `multishot` 和传说稀有度，避免破坏已有构筑识别。
- Lv.1：投射类武器 +1 弹道、闪电链增加传导跳数、相位刃增加一枚；每8秒自动锁定并攻击一名敌人。
- Lv.2：自动齐射最多命中2个目标，间隔缩至6.5秒。
- Lv.3：弹道累计+2，齐射最多攻击3个目标。
- Lv.4：齐射伤害增强，间隔缩至5秒，最多攻击4个目标。
- Lv.5：星穹超载，弹道累计+3，每3.5秒齐射最多攻击5个目标。
- 星穹齐射是一套独立的攻击机制，不会生成无限弹药；飞弹同一轮实体数量最多16枚。冻结、遗物和等级的伤害加成仍按正常命中规则计算，不会重复计算等级伤害。

## 操作

| 平台 | 移动 / 方向 | 折跃 | 其他 |
| --- | --- | --- | --- |
| 键盘 | WASD / 方向键 | 空格 | P/Esc 暂停，F 全屏 |
| 鼠标 | 自动锁定附近敌人 | 右键 | 左键常规射击 |
| 触控 | 左侧虚拟摇杆 | 右下 DASH | HUD 按钮切换功能 |
| 手柄 | 左摇杆移动，自动锁定附近敌人 | A / B / RB / RT / LB / LT | Start 暂停，升级弹框左右选择并 A 确认 |

触屏支持双指同时操作：左手按住动态摇杆控制方向，右手点击、拖动或松开 DASH 都不会导致左手摇杆丢失方向。触点通过浏览器 `Touch.identifier` 区分；只有移动手指抬起或触控取消才释放摇杆。开始新局、暂停和结束时会清理残留的摇杆状态。

手柄震动受浏览器、操作系统、连接方式和硬件支持影响。升级卡片确认后需要松开操作键才会恢复战斗折跃，防止确认键穿透。

## V3 无尽模式（肉鸽系统）

普通模式首次击败Boss后点击「进入无尽炼狱」。此时不重置武器、经验和六阶难度，立刻开启三选一遗物奖励，然后选择下一战区。

- **Boss 循环与奖励**：每三分钟一轮 Boss；每轮击破后再选择随机遗物或满足前置条件的武器融合，之后重新选路线。
- **战术遗物**：16件，去重抽取（普通/稀有/传说按权重），包括精准折跃、低血量爆发、对Boss增伤、冰冻构筑、精英回血、击杀连击等。遗物随本局保存，不能突破九段/0.40秒上限。
- **武器融合**：五组，满足对应武器/折跃升级条件（普通武器至少Lv.3，折跃相关至少Lv.2）后才可能进入Boss奖励池。不占武器或模组槽位；每组只获得一次。
- **战区路线**：猎杀（精英更密集、敌方血量提高）、补给（治疗/磁铁掉率×1.5）、裂隙（敌方血量提高，击杀Boss奖励晶体）。
- **战术事件**：无尽期间有8种任务，包括击杀挑战、精英猎首、精准折跃、无伤生存、禁用折跃等。成功获得25晶体及12点治疗；失败不提供奖励。HUD显示进度与剩余时间。
- **Boss随机词缀**：量子装甲、再生核心、散射轰炸、狂热推进、召唤大师，前期一条、后续轮次最多两条，受到同屏弹幕与召唤数量预算约束。
- **无尽升级卡**：普通/稀有/传说的基础抽取权重60/28/12（归一化且不放回）；初始拥有2次重随、2次永久禁用；允许跳过当前升级获得12晶体。手柄Y重随、X禁用选中的卡；鼠标和触屏可直接点击按钮。
- **暂停战斗**：在三选一遗物/融合和路线选择时，游戏时钟停止；选完继续。不自动为玩家决策。

特殊事件在下一Boss到来之前触发，且不会覆盖六阶进阶难度。遗物和融合都是本局增益，下一次重新部署会重置。

## V4 局域网双人合作与房主暂停

双方打开部署在 Vercel 的游戏页面；房主选择「创建房间」获得6位房间码，队友输入房间码（或打开预填房间码的邀请链接）后可自动交换WebRTC连接信息。**不需要互相复制大段JSON**。如果临时信令不可用，可展开「高级连接 / 手动配对」完成原来的邀请/应答交换。同源浏览器标签页也能通过 BroadcastChannel 发现房间。

Vercel Hobby 只承担 Next.js API 信令：配置免费的 Upstash Redis REST 地址/令牌到 `UPSTASH_REDIS_REST_URL` 和 `UPSTASH_REDIS_REST_TOKEN` 环境变量后重新部署。房间数据5分钟过期，不需要运行独立游戏服务器或配置数据库表。**战斗信息不经过Vercel或Redis**，摇杆、折跃、敌人和快照通过两台浏览器直接建立的WebRTC DataChannel传输。默认不配STUN/TURN服务器，若Wi-Fi隔离、网络不可达将无法建立局域网连接；不是跨设备局域网广播自动搜房。

### 联机怪物与专属Boss

- 联机普通怪生命 ×1.35、精英 ×1.45、Boss ×1.65，敌人伤害约 ×1.12，刷怪间隔缩短约10%；单人难度不变。
- 第2、4、6……轮联机Boss为「双生裁决者 · 共振要塞」。两名玩家需要分别进入Boss左右光圈，持续同时占位1.4秒才能破盾；破盾后核心暴露9秒，受到的伤害提高。Boss交替追击双方并经过0.7秒预警释放双路弹幕。
- 战胜该Boss双方恢复25点生命，队伍得到额外35晶体。该玩法由房主权威判定，不依赖云服务器计算。

### 共享经验与全图磁铁

- **队伍共用一套等级与经验池**。任一玩家拾取经验晶体都只计算一次，另一玩家同步看见相同的经验和等级；经验不按最后一击或距离竞争拆分，避免重复得分。
- 任一玩家拾取「全图吸经验」磁铁后，全部经验晶体会飞向最近的存活玩家，最终进入同一共享经验池。磁铁不会远程吸取/触发治疗、核弹等特殊道具。
- 治疗道具归实际拾取者。双方各自从相同升级定义中选择个人武器、模组和折跃，房主负责校验房客的升级并计算伤害；无尽模式团队投票、四人模式和断线重连尚未实现。

### 双人救援与全局坚持计时

1. 任一玩家生命归零，进入**倒地状态**，不能移动、攻击或折跃；存活玩家继续挑战。
2. 首次倒地时需要坚持 **8秒**；此后房主和房客的**累计倒地次数共用**，每多一次倒地，下一次救援增加4秒，上限40秒（8、12、16、20……40秒）。
3. 存活者靠近倒地队友至145游戏单位内，连续保持3秒后，救援倒计时开始以两倍速度推进；移开则恢复正常倒计时。没有跳过死亡惩罚的瞬间复活。
4. 坚持成功后倒地者在存活队友旁复活，恢复 **40%最大生命**，享有 **2秒无敌**。暂停与升级弹窗期间不计时。
5. **只有两名玩家同时倒地才结束整局**。双方均可倒地和救援，不再有「房主一死立刻结算、房客固定8秒复活」的不公平机制。
6. 战斗画面持续显示累计倒地次数、累计实际坚持时间和下一次救援时间；倒地时显示双方同步的倒计时。统计每局独立，重新开局归零。

### 暂停由房主控制

- 只有房主能通过顶部按钮、键盘P/Esc或手柄暂停与恢复整局游戏。暂停后双方停止移动、攻击、折跃，敌人/Boss与经验系统停住，房客屏幕会出现「房主已暂停，请等待房主继续游戏」。
- 房客无法暂停或恢复整个战场，但可以独立打开个人设置而不打断房主。房主打开设置则同时暂停全局。
- 恢复后继续同一局；房客需发送新的操作，不会补发暂停期间积压的折跃事件。

**现阶段范围**：房主 + 1 名房客，房主运行唯一战斗世界，房客使用轻量快照渲染；房客只有初始3段折跃、基础自动射击及同步等级，暂不支持完整个人武器升级、全套无尽决策、四人模式与断线重连。跨手机与电脑的真实LAN/浏览器验收仍是上线前必做项。

## V4 手机设置与战场视角

首页、游戏HUD与暂停菜单均可打开「游戏设置」。画面设置增加 **65%–150% 战场视角缩放**：低于100%可看见更大范围，高于100%能放大战机与敌群；只影响战斗画布，不改变按钮、HUD和菜单。房客可单独调整自己的镜头，不影响房主。

全部偏好自动缓存到当前设备浏览器的 `neon_game_settings_v1`，重新开局、刷新页面或横竖屏旋转后仍会恢复，**无需每局重新设置**。包括缩放、按钮大小与透明度、摇杆死区、音效、震动、CRT和低特效。**自动瞄准始终开启**，无论键鼠、触屏还是手柄操作都不能关闭，旧存档中的关闭配置也不再生效。移动端横竖屏均保留全屏按钮，电脑可用 F 键切换全屏；某些浏览器可能限制网页全屏功能。

UI按照视口宽高自适应：竖屏战斗HUD双排、升级卡纵向展开；横屏低高度采用紧凑HUD，升级/房间/设置弹窗可滚动，且兼容手机刘海及系统安全区域。联机房客可通过悬浮设置按钮调整偏好。

### 队友位置气泡、昵称和战机颜色

进入「游戏设置」→「联机身份 · 战机外观」，可以输入最多12个字符的战机昵称，并设置蓝、橙、紫、绿、粉、金等机体霓虹色；默认「自动区分」为房主蓝色、房客橙色。联机房间页面也有「修改昵称 / 战机颜色」快捷入口。

昵称和颜色随本机设置自动缓存，每次组队仍然生效。双方进入同一房间后，房主/队友战机的描边、座舱光效和头顶文字都使用自己的设置，联机途中修改也可同步到队友设备。

**队友离开可视范围**时，屏幕安全边界会出现一个彩色的小气泡，显示队友名字、方向箭头和与自己的距离（游戏世界坐标单位）；队友返回当前视野后气泡自动隐藏。气泡会考虑每台设备自身的65%–150%镜头缩放，手机横竖屏切换也会自动重新计算，不会挡住主要触控按钮。局域网双方仍须先完成WebRTC连接，此定位不是跨设备搜房功能。

## 存档与统计

仅使用本地存储，不依赖联网。旧记录 `neon_best_time` / `neon_best_kills`、震动设置 `neon_vibration` 不会被删除。新增：

- `neon_ascension_unlocked`：最高已解锁阶级（0–6）
- `neon_difficulty_selected`：开始界面已选择阶级
- `neon_ascension_records_v2`：每档尝试次数、获胜次数、最高击杀和最高生存秒数
- `neon_endless_records_v3`：每个进阶难度下的无尽尝试次数、最佳阶段、最长生存秒数和单局最多遗物数

暂停 / 结束成绩中附有难度、当前无敌覆盖率、精准折跃和全局毁灭掉落次数，便于平衡观察。

## 开发维护与验证

- 游戏主入口为 `index.html`，核心代码位于 `js/core.js` 中的 `NeonSurvivorGame`；六阶规则集中于 `NEON_DIFFICULTIES`，光环时长集中于 `NEON_AEGIS_DURATIONS`。
- 肉鸽扩展拆为 `js/endless.js`（阶段与路线）、`js/relics.js`（遗物）、`js/fusions.js`（武器融合）、`js/events.js`（限时事件）、`js/ui.js`（奖励菜单与HUD）；样式在 `css/game.css`。
- `getDifficultyRules()` 提供掉落、敌人伤害、数量和精英频率系数；`getPassiveSlotLimit()` 负责进阶 V 后模组限额。
- `rollNormalDrop(roll, source)` 集中掉率判断；`source === 'nuke'` 禁止新的核爆道具掉落。
- `getEffectiveDashRecharge()` 统一 HUD 和主循环充能时间；`recalculateDashStats()` 负责九段储能与无敌圈重算。
- `combatTelemetry` 在整局初始化，统计无敌覆盖率、精准折跃、道具和承伤。正式均衡调校应增加固定种子与多次实战，不能把一次测试视为数值定案。
- `setupTouchControls()` 绑定属于移动摇杆的触点 ID，使用 `changedTouches` 更新它；右手 DASH 的事件不会重置摇杆。触控退出时通过 `releaseJoystickTouch()` 清理状态。
