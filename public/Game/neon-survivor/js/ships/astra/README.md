# 星织·织界术师（ASTRA）

**状态：已开放（`playable: true`）**。星能法师/辅助/范围输出混合舰，9 武器、8 被动、7 相位强化组成专属升级池。代码集中于 `ship.js`、`abilities.js`、`weapons.js`、`upgrades.js`、`effects.js` 和 `network.js`。

装备容量由本舰的 `ship.js` 统一声明：**4 武器槽 / 4 被动槽 / 7 种不同相位强化 / 2 个主动法术**；进阶 V–VI 被动槽为 3。初始星梭占用一个武器槽；主动法术不占武器或被动槽。

## 基础参数、星能与主动技能

| 项目 | 默认值 / 行为 |
|---|---|
| 初始生命 | 95 HP |
| 基础移速 / 回血 | 235 / 0.8 HP/s |
| 初始武器 | 星梭织阵 `star_weave` Lv.1（Lv.1~5 发射 1~5 发自导追踪星梭） |
| 星能池 | 开局 60 / 上限 100（`star_talisman` 最高扩至 200）；平时自然恢复 2.0 点/秒（`ley_conduit` 最高叠至 7.0 点/秒） |
| 命中回能（星能回流） | 单目标触发间隔 1.5 秒，按等级 Lv.1/6/12 单次回复 3/4/5 点；平时全局上限 **12.0 点/秒**，开启天界结界期间硬上限锁死为 **6.0 点/秒**（且结界期间自然恢复暂停） |
| 苍穹星陨 `[K]`（进攻） | **0 CD 无冷却**，固定消耗 **12 星能/发**（无命中返能与减冷却机制），基础伤害 36，半径 105，最多命中 9 个目标，附带 0.6 秒短暂群体击晕并在落点留下 **滞留 3 秒的 50% 减速区** |
| 天界结界 `[J]`（移动炮台） | 开关切换（需 ≥20 星能启动，启动耗 15 星能，维持消耗 **20 星能/秒**，关闭后 8 秒冷却）；法阵随舰移动，半径 160（受 `glyph_extent` 扩大），自身全伤害 **+70%（×1.70 独立乘区）**、减伤 25%、神圣灼烧 DoT、内圈 45% 半径绝对推怪并湮灭敌弹；期间移速 -80% 且禁闪现，关闭/耗尽时获 35 点临时护盾与 2.5 秒 +50% 移速及击退波 |
| 相位闪现 `[空格]` | 初始 2 段，强化最多 4 段，瞬移距离 160，基础恢复周期 5 秒，短暂保护 0.12 秒并获 2 秒 +50% 移速 |
| 职业连线支援 | 与存活队友保持有效连线时，周期性提供短效护盾（包含本人）；不向全地图无条件发盾 |

攻击和防守术式从进入战斗时就都可用，二者消耗**同一个星能池**，但有独立冷却。键盘 J/K、手柄 X/Y 分别直接施放结界和星陨；触屏点击战术技能栏对应图标即可，无需切换。空格/手柄 RT/移动端 DASH 触发相位闪现。自动索敌，不要求客户端上传目标或伤害。

## 专属 9 武器

| ID | 名称 | 效果方向 |
|---|---|---|
| `star_weave` | 星梭织阵 | 初始自导星梭（1~5发）命中部署星锚（最多3处），连线每 0.5 秒切割、满级三角星网每 6 秒坍缩爆发 |
| `star_fragments` | 星陨碎片 | 追踪敌人后延迟定点轰击并施加星痕标记 |
| `prism_split` | 棱镜分光 | 多目标折射的能量链（最多8目标） |
| `chrono_bind` | 时序束缚 | 范围减速/控场和法术伤害 |
| `eclipse_seal` | 月蚀法印 | 延迟区域法印爆炸 |
| `returning_orb` | 折返星轮 | 向外放射后回收，产生双向命中 |
| `void_shock` | 虚界震荡 | 向最近敌群扇形冲击 |
| `sky_meteor` | 苍穹流星 | 多个错时落点的持续轰炸 |
| `singularity_chant` | 奇点咏唱 | 长时间蓄力的大范围高伤爆发 |

默认星网在目标附近生成星锚；连接两点形成攻击线，升级后最多形成三角星网。4 槽法术武器与主动技能独立计时、伤害完全叠加，且全部享受天界结界的 +70% 增伤。

## 推荐构筑与联机

- **进攻流**：星梭织阵 + 星陨碎片 + 苍穹流星，优先星痕追猎、专注、法阵延展；保留足够星能施放星陨。
- **防守流**：灵脉导流、星能护符、护盾折射与虚相护体，优先及时布置固定位置结界。
- **混合流**：星梭 + 时序束缚 + 星穹回响，星陨命中可同时打出额外爆发并生成自保护盾，不要求交替施法。所有流派只是建议，不锁定自由构筑。
- **双人**：与裂锋连线时裂锋给队伍攻击加成，星织按有效距离向连线内成员周期性提供护盾；护盾数值随队伍等级与怪物强度平滑成长。房客施法只发送法术 ID/序号，房主校验星能、冷却、距离并计算伤害，快照同步远端星能/星网/结界。
