# 裂锋·虚空突击者（RIFTBLADE）

**状态：已开放（`playable: true`）**。战舰 ID `riftblade`，进攻/近距离折跃定位，默认推荐首次游玩。角色配置见 `ship.js`，造型见 `renderer.js`；升级规则在通用 `core.js` 的 `UPGRADES_DB` 中，旧裂锋玩法保持兼容。

## 开局与操作

| 属性 | 初始值 |
|---|---:|
| 生命 / 最大生命 | 100 / 100 |
| 基础移速 | 240 |
| 基础回血 | 0.8 HP/秒 |
| 折跃充能 | 3 段；升级最多 9 段 |
| 初始武器 | 脉冲离子炮 Lv.1（`blaster`） |
| 固有特点 | 传统进攻折跃：高速移动、沿冲刺路径切割敌人 |

自动锁敌；WASD/方向键或左摇杆移动，空格、鼠标右键、触屏 DASH、手柄 A/RB 等触发折跃。静止时按自动锁敌方向折跃。精准穿越增加折跃连击；技能的冷却、无敌和伤害数值按游戏当前难度与升级结算。

## 8 种被动

强核反应堆 `power`（武器伤害）、超频加速卡 `haste`（冷却）、矢量推进器 `thruster`（移速/折跃）、强引力透镜 `magnet`（拾取范围）、纳米修复装甲 `armor`（减伤/回血/极限保命）、量子弱点瞄准仪 `crit`（暴击）、星穹火控矩阵 `multishot`（额外弹道与传说齐射）、高维拓扑透镜 `area`（攻击范围）。被动装备槽默认最多 4 个，较高进阶难度会减少槽位。

## 单人/联机

单人使用全部自身武器与进攻折跃机制。局域网合作时，升级候选与资源独立于队友，怪物和伤害由房主结算，昵称、船型和武器命中归属按玩家 ID 同步。裂锋在有效队伍连线内提供随等级成长的额外攻击加成；星织可提供独立护盾，幽灵可作为共生炮手挂载裂锋。升级卡先预选、确认后才生效，取消不会消耗机会。

## 实现与限制

- 舰体属性和造型完全由 `ship.js`、`renderer.js` 自动注册；旧升级与传统射击逻辑仍保留在通用核心中作为基础舰实现。
- 真实四设备联机仍需专门验收；三舰开放不等于宣称所有平台的 3/4 人联机已经完成。
