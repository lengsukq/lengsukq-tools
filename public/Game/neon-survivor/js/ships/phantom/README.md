# 幽灵·共生拟态（PHANTOM）

**状态：已开放（`playable: true`）**。潜行、灵质收集、烙印引爆和队友共生混合舰。所有专属文件放在本目录，由 `ships.generated.js` 自动注册；没有单独的后端角色服务。

装备容量由本舰的 `ship.js` 统一声明：**4 武器槽 / 4 被动槽 / 7 种潜行强化 / 2 个主动动作**；进阶 V–VI 被动槽为 3。初始幽魂之镰占用一个武器槽；潜行与共生动作不会抢占装备槽。

## 初始属性与固有机制

| 项目 | 规则 |
|---|---|
| 初始 HP / 基础移速 | 85 / 260 |
| 自然回血 | 0.5 HP/秒 |
| 初始武器 | 幽魂之镰 `phantom_scythe` Lv.1，自动往返切割 |
| 灵质池 | 开局 0，基础上限 100；由镰刀命中、烙印、共生等途径收集 |
| 虚无潜行 | 初始 2 次充能、每次持续 1.6 秒，期间提高移速并避免普通受击 |
| 充能恢复 | 每段基础恢复 5.5 秒，升级灵能超蓄后最多 3 次 |
| 烙印引爆 | 潜行穿过或贴近敌人留下 4 秒烙印；再次触发折跃键或潜行结束时引爆，伤害按等级、灵质、目标数增长且有单次上限 |
| 共生挂载 | 双人/多人时靠近活着的队友（150 距离内），按 Q 或触控「共生合体」挂载；再次操作可弹射脱离 |
| 共生限制 | 单次最长 14 秒，结束后 8 秒冷却；载体得到协同射击/生存增益，挂载中的幽灵仍使用自己的武器 |

### 操作

WASD/方向键、左摇杆移动，自动锁敌；空格/右键/手柄 A/RB/触控 DASH 开始潜行，再按折跃键对烙印目标斩魂引爆；潜行也会在持续时间结束时自动结算。**Q / 手柄 X / 触控「共生合体」**在联机中挂载或脱离队友；单人模式无需队友即可玩完整潜行与武器体系，但不能自行触发双人挂载。

## 9 种专属武器

| ID | 名称 | 特性 |
|---|---|---|
| `phantom_scythe` | 幽魂之镰 | 初始双镰投掷、盘旋、回收；回收恢复灵质，高等级可追加爆发 |
| `spectral_dart` | 虚界毒刺 | 多目标追踪毒刺，提升目标数和伤害 |
| `soul_reap_orb` | 噬魂法球 | 目标链伤害并回收灵质 |
| `void_rift_mine` | 虚空裂隙雷 | 在敌人位置部署 0.55 秒后引爆的地雷 |
| `symbiote_beam` | 共鸣射线 | 打击多个目标；共生时对载体有少量生命恢复 |
| `haunt_clones` | 游荡残影 | 错时生成多个追踪残影冲击区 |
| `curse_totem` | 幽冥死灵图腾 | 延时范围伤害；潜行时还可施加烙印 |
| `apocalypse_scythe` | 终焉断头台 | 周期性广域镰刀斩击，最多 16 目标 |
| `abyssal_possession` | 深渊拟态侵蚀 | 高额单体侵蚀，附带普通敌人的减速与单次伤害限制 |

除初始幽魂之镰外的八种专属武器分别有自己的自动触发周期、等级伤害/目标数和实体或区域预算。全部由房主战斗世界计算，不信任房客提交的伤害数值。武器最高等级 5。

## 推荐构筑

- **潜袭爆发**：幽魂之镰、破败残响、烙印剧变与虚空漫步；绕过敌人布置烙印后集中引爆。
- **安全持续输出**：虚界毒刺、噬魂法球、灵能涌流、相位消隐装甲；积累灵质稳定输出。
- **共生辅助**：共鸣射线、共生共振环、双极意识、共生弹弓；在队友附近挂载支援后及时脱离。单人不能触发挂载，仍可自由选择攻击/防守混合构筑。

## 联机与技术边界

房主/房客都可以选幽灵。房客的折跃动作、共生挂载/脱离只传入经校验的输入、动作 ID 与单调序号；由房主判定近距离、冷却、资源、斩魂命中和载体状态。WebRTC 快照仅携带有大小限制的灵质、潜行、储能和镰刀位置；不会把灵魂烙印引用、内部 Map 或敌人伤害公式暴露给客户端。

本舰独立文件：`ship.js`（初始属性）、`renderer.js`（双镰舰体）、`abilities.js`（潜行/24 卡/共生）、`weapons.js`（幽魂之镰）、`arsenal.js`（另外八种武器）、`network.js`（资源快照）、`effects.js`（本机和远端特效）。测试：`node tests/neon-survivor-phantom-foundation.smoke.cjs`、`node tests/neon-survivor-phantom-scythe.smoke.cjs`、`node tests/neon-survivor-three-playable-ships.smoke.cjs`。

代码冒烟可以证明功能已接入和基本结算，但不代表已在所有移动浏览器与真实四台设备上逐项验收性能和 WebRTC 连通性。
