🎮 游戏手柄控制 (GAMEPAD)

兼容浏览器 Gamepad API 的 Xbox / PlayStation / Switch / PC 手柄；震动能力取决于浏览器、操作系统和连接方式：

  • 左摇杆 / 十字键：360° 模拟飞行移动与八向平移
  • 自动瞄准：始终开启，无需操作右摇杆
  • X 键 / Y 键：释放战舰专属战术技能（对应键盘 J / K：星织为天界结界/苍穹星陨；幽灵为幽影疾行/虚空力场(潜行吸怪/非潜行推怪)，联机靠近按 LB / Q 共生）
  • A 键 / B 键 / RB / RT / LB / LT：折跃瞬移斩（裂锋 3~9 段） / 相位闪现（星织 2~4 段） / 幽灵潜行（幽灵 2~4 段充能）
  • 开始界面：十字键左右切换已解锁的进阶难度，A 确认开局
  • Start / Options 键：暂停游戏 / 呼出菜单
  • 升级面板操作：摇杆/十字键左右选卡，A 预选（再次 A 确认），X 或 RT 一键确认，B 取消预选，Y 保留升级机会。无尽模式 X 放逐、Y 重掷、RT 确认；按键提示仅在手柄连接后出现
  • 震动反馈与测试：顶部 📳 是开关；点击已连接手柄徽章或「震动测试」按钮可主动检测
⌨️ 键盘与鼠标 (KEYBOARD & MOUSE)
  • W / A / S / D 或 方向键：战机飞行移动
  • J 键 / K 键 / Q 键：释放战舰专属主动战术技能（星织：[J] 开启/关闭天界结界炮台、[K] 0 CD 苍穹星陨连轰；幽灵：[J] 幽影疾行加速、[K] 虚空力场(潜行吸怪/非潜行推怪)、[Q] 联机战术共生挂载；也可直接点击右下角技能图标）
  • 空格键 或 鼠标右键：裂锋折跃瞬移斩 / 星织相位闪现 / 幽灵潜行与引爆
  • 自动瞄准：始终开启，战机会自动锁定附近敌人；鼠标左键可手动辅助瞄准射击
  • F 键：一键进入 / 退出全屏模式；P 键 / ESC 键：快速暂停游戏
📱 触屏移动端 (TOUCH CONTROLS)
  • 左侧区域：按住滑动呼出动态虚拟摇杆，控制机体自由飞行
  • 右侧战术技能区 & DASH 键：直接点击对应技能按钮释放专属战术技能（J/K）与折跃/闪现/幽灵化身；机库开局前可切换「王者式弧形 / 紧凑横向」及左右手布局
  • 双指联动：左手持续按住摇杆移动，右手点击或松开技能键均不会打断左手方向控制；仅松开左手摇杆时停止控制
  • 顶部状态栏：轻触右上角全屏、设置与说明按钮；房主可暂停游戏
🛸 舰队编制与独立机制总览 (FLEET ARCHETYPES)

深空防线现已列装三型特化作战战舰，每艘战舰拥有完全独立的基础属性、初始专属武器、独有主动战术技能、折跃进化树及专属升级卡池（裂锋使用通用科技池，星织与幽灵各自拥有 24 张专属战术卡牌）：

  • 装备槽位：三舰均为 4 个武器槽（初始武器占 1 格）、4 个被动模组槽（进阶V~VI为 3 槽）、最多 7 种折跃强化卡牌。
  • 局内绑定：开局选定战舰后整局生效不可更换；联机模式中各玩家战舰互不冲突、独立运算与结算。
