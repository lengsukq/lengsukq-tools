🎮 游戏手柄控制 (GAMEPAD)

兼容浏览器 Gamepad API 的 Xbox / PlayStation / Switch / PC 手柄；震动能力取决于浏览器、操作系统和连接方式：

  • 左摇杆 / 十字键：360° 模拟飞行移动与八向平移
  • 自动瞄准：始终开启，无需操作右摇杆
  • A 键 / B 键 / RB / RT / LB / LT：消耗一段折跃充能；从3段最多成长至9段
  • 开始界面：十字键左右切换已解锁的进阶难度，A 确认开局
  • Start / Options 键：暂停游戏 / 呼出菜单
  • 升级面板操作：左摇杆/十字键左右切换卡片，A/RT键确认装配
  • 震动反馈与测试：顶部 📳 是开关；点击已连接手柄徽章或「震动测试」按钮可主动检测
  • 震动无效？：先操作手柄并点击测试。若提示不支持，可换支持震动的浏览器或尝试 USB 连接。浏览器接受震动请求并不代表硬件一定执行
⌨️ 键盘与鼠标 (KEYBOARD & MOUSE)
  • W / A / S / D 或 方向键：战机飞行移动
  • 空格键 或 鼠标右键：消耗 1 格能量折跃瞬移斩
  • 自动瞄准：始终开启，战机会自动锁定附近敌人
  • 鼠标左键：开火射击（武器也会自动攻击）
  • F 键：一键进入 / 退出全屏模式
  • P 键 / ESC 键：快速暂停游戏
📱 触屏移动端 (TOUCH CONTROLS)
  • 左侧区域：按住滑动呼出动态虚拟摇杆，控制机体自由飞行
  • 右下角 DASH 按钮：轻触释放折跃瞬移斩（实时展示可用充能）
  • 双指联动：左手持续按住摇杆移动，右手点击或松开 DASH 均不会打断左手方向控制；仅松开左手摇杆时停止控制
  • 顶部状态栏：轻触右上角全屏、设置与说明按钮；房主可暂停游戏

⚡ 独立九段折跃专精 (WARP MASTERY)

折跃冲刺独立于武器与模组槽，可由初始3段逐步升级至9段。精准穿越敌人可累积连击奖励，瞬移路径造成切割伤害：

  • 时空无敌光环：六级精细成长 0.15/0.20/0.25/0.30/0.35/0.40 秒；与折跃无敌保护重叠，不累加；六级终结释放8向激光
  • 精准折跃连击：贴近敌人核心完成斩击，可连续积累至5层精准奖励，每层精准伤害+8%，超时或空斩中断；不会返还无敌或折跃次数
  • 落点爆轰：折跃目的地引发超新星核爆与引力坍缩聚怪
  • 等离子火墙：身后留下持续蒸发敌人的离子隔离带
  • 极光冰霜：闪烁穿刺附带大范围强力深度冻结
📦 4武器 + 4模组与超频破限

标准难度最多同时装备 4 款主动武器 与 4 款被动模组；进阶V及以上只有3个模组槽位，折跃升级独立。满级后的超频破限 (Limit Break)继续强化伤害与范围，但无敌光环时长不再无限提升。
